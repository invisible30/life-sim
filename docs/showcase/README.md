# Showcase

These HTML / JSON files are committed to the repo as a "what this project
produces" demo. They were generated by:

- `compare.html` — a 10-seed parallel run on MiniMax `MiniMax-M2.7-highspeed` (Aug 2026)
- `biography.html` / `log.json` — a single seed=42 run

## Why these live in `docs/showcase/`, not `output/`

Earlier versions of this project kept the showcase in `output/seed42/`. The
problem: anyone who clones the repo and runs `python main.py` would overwrite
the showcase files (because the default seed in `.env.example` is 42). The
README pointed to files that disappeared the moment anyone ran the project.

These files now live in `docs/showcase/` which `output/` never writes to.
Local runs are unaffected.

## How to regenerate locally

```bash
# single life (overwrites output/, not docs/showcase/)
python main.py

# 10 seeds
python multi_run.py --seeds 10 --workers 4
```

## File sizes

- `biography.html` — ~4.5 MB (Jinja2 + Chart.js, every decision's debate)
- `compare.html` — ~23 KB (10 seeds × 5 metric radar + scorecard)
- `log.json` — ~2 MB (one life's full decision log)
